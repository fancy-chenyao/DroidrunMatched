## 🎯 功能概述

### 核心价值

当 DroidRun 的热启动失败时，Failure Reflection 能够：

1. 🤔 **自动分析**失败原因（UI变化、参数不匹配、环境差异等）
2. 💡 **生成建议**提供具体的修复建议
3. ✨ **增强任务**将建议融入冷启动任务描述
4. 📝 **保存经验**失败反思持久化到 Memory 系统

## 🎯 核心技术实现

### 技术架构

```
┌─────────────────────────┐
│      DroidAgent         │  ← 调用方
│  - enable_reflection    │
└───────────┬─────────────┘
            │ 热启动失败
            ↓
┌─────────────────────────┐
│   FailureReflector      │  ← 核心模块
│  - analyze_failure()    │
│  - LLM 调用             │
│  - 缓存机制             │
│  - 置信度计算           │
└───────────┬─────────────┘
            │
            ↓
┌─────────────────────────┐
│   FailureReflection     │  ← 结果
│  - problem_type         │
│  - root_cause           │
│  - specific_advice      │
│  - confidence           │
└───────────┬─────────────┘
            │
            ├─→ Trajectory.failure_reflections
            └─→ Experience.metadata.failure_reflections
```

   ```python
   # 最多 3 个差异
   ```

   
   **效果**: 响应时间 ↓95%
