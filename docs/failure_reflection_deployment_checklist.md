## 🐛 回滚计划

### 紧急回滚

**触发条件**:
- LLM 服务大面积故障
- 错误率 >5%
- 性能严重下降

**回滚步骤**:

1. **配置回滚**:
   ```yaml
   agent:
     failure_reflection: false  # 快速禁用
   ```

2. **重启服务**:
   ```bash
   # 重启 DroidRun 服务
   ./restart.sh
   ```

3. **验证**:
   - [ ] 功能恢复正常
   - [ ] 性能恢复
   - [ ] 无新错误

**预计回滚时间**: <5 分钟

---
