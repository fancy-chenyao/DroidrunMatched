## 🔧 技术架构

### 核心组件

```
┌─────────────────────────────────────────┐
│           DroidAgent (调用方)            │
│  - enable_failure_reflection            │
│  - failure_reflector: FailureReflector  │
└────────────────┬────────────────────────┘
                 │
                 │ 热启动失败触发
                 ↓
┌─────────────────────────────────────────┐
│        FailureReflector (核心)           │
│  - analyze_failure()                    │
│  - _call_llm_for_analysis()             │
│  - _calculate_confidence()              │
│  - _cache: Dict (缓存)                  │
└────────────────┬────────────────────────┘
                 │
                 ├───→ LLM 调用
                 ├───→ 缓存检查
                 └───→ 结果计算
                 │
                 ↓
┌─────────────────────────────────────────┐
│      FailureReflection (结果)            │
│  - problem_type                         │
│  - root_cause                           │
│  - specific_advice                      │
│  - confidence                           │
└────────────────┬────────────────────────┘
                 │
                 ├───→ Trajectory.failure_reflections
                 └───→ Experience.metadata.failure_reflections
```

---

### 数据流

```
热启动失败
    ↓
创建 FailureContext
    ↓
检查缓存
    ├─ 命中 → 返回缓存结果 (<10ms)
    └─ 未命中 ↓
    调用 LLM 分析 (2-3s)
    ↓
解析响应
    ↓
计算置信度
    ↓
保存到缓存
    ↓
保存到 Trajectory
    ↓
保存到 Experience
    ↓
增强任务描述
    ↓
执行冷启动
```
